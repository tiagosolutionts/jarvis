# Bem-vindo ao Jarvis

Este é o seu **Vault**: uma pasta comum no seu computador. O Jarvis enxerga tudo aqui — notas, JSON, planilhas, imagens, sites HTML e scripts.

## Experimente dizer
- "Jarvis, qual é a missão do dia?"
- "Jarvis, cria um roteiro de Reels sobre phishing para pequenas empresas."
- "Jarvis, adiciona a tarefa ligar para o cliente amanhã."
- "Jarvis, lembra que minha reunião semanal é toda segunda às 9h."
- "Jarvis, abre a planilha de clientes."

## Estrutura
- `.jarvis/instrucoes.md` — regras permanentes
- `.jarvis/skills/` — habilidades (uma pasta com `SKILL.md` cada)
- `.jarvis/commands/` — comandos rápidos `/nome`
- `.jarvis/memoria.md` — o que ele aprendeu sobre você
- `Tarefas.md` — compatível com Obsidian/Tasks
