# Skill: Resumo de reunião

1. Leia o arquivo indicado (ou o texto colado).
2. Gere: **Contexto**, **Decisões**, **Pendências** (responsável + prazo), **Riscos** e **Próximos passos**.
3. Salve em `Notas/AAAA-MM-DD Reunião <cliente>.md`.
4. Para cada pendência minha, chame `adicionar_tarefa` com a data no formato 📅 AAAA-MM-DD.
5. Em voz: diga quantas decisões e quantas tarefas foram criadas.
